# 3D Compare Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new **3D Compare** mode that races your uploaded game lap against a real F1 driver's lap on the 3D track, with a live time gap, overlaid telemetry and per-corner gains and losses.

**Architecture:**
- **Backend:** `POST /analyze` gets a new mode, `compare_3d`. It runs the existing game-vs-real pipeline, builds the pro lap exactly like `GET /pro_lap`, and adds `you`: your timing and inputs resampled onto the pro lap's 2 m distance grid, using the pipeline's alignment anchors.
- **Frontend:** the existing `learn3d/` viewer gains an optional second car. Your lap becomes a normal `points` object (pro geometry plus your `t`/inputs), so the existing `stateAt` already answers "where is your car at time t". One clock drives both cars.

**Tech Stack:**
- Backend: Python 3.11, FastAPI, numpy/pandas, pytest.
- Frontend: vanilla ES modules, Three.js 0.170.0 (jsDelivr importmap), `node --test`, Playwright MCP for the browser check.

**Spec:** `docs/superpowers/specs/2026-10-15-3d-compare-design.md`

```python
def _build_you_lap(aligned, d_grid, lap_time: float) -> dict:
    """Your game lap resampled onto the pro lap's distance grid, for the 3D compare view.

    ``aligned`` has one row per game metre; the pipeline's alignment anchors
    (``aligned.attrs``) map each game metre to real lap distance, the axis ``d_grid``
    (from ``_build_pro_lap``) uses. Time comes from integrating game speed, pinned to
    ``lap_time`` like the pro lap.
    """
    game_d = aligned["lap_distance"].to_numpy(dtype=float)
    real_d = np.interp(game_d, aligned.attrs["game_anch_d"], aligned.attrs["real_anch_d"])
    real_d = np.maximum.accumulate(real_d) + np.arange(game_d.size) * 1e-6   # strictly increasing for interp
    v = np.maximum(aligned["game_speed_kmh"].to_numpy(dtype=float) / 3.6, 1.0)
    t = np.concatenate([[0.0], np.cumsum(np.diff(game_d) / ((v[1:] + v[:-1]) / 2))])
    t *= lap_time / t[-1]
    d_grid = np.asarray(d_grid, dtype=float)

    def col(values):
        return np.interp(d_grid, real_d, np.asarray(values, dtype=float))

    def rnd(values, digits):
        return [round(float(x), digits) for x in values]

    return {
        "t": rnd(col(t), 3),
        "speed": rnd(col(aligned["game_speed_kmh"]), 1),
        "throttle": rnd(col(aligned["game_throttle"]), 3),
        "brake": rnd(col(aligned["game_brake"]), 3),
        "gear": [int(g) for g in np.rint(col(aligned["game_gear"]))],
    }
```

def _compare_3d_payload(payload: dict, aligned, report, driver: str, year: int,
                        session: str, track: str) -> dict:
    """3D Compare: the comparison header plus the pro lap (as /pro_lap) and your lap on its grid."""
    if track not in {t["key"] for t in _discover_tracks()}:     # the json path is built from it
        raise HTTPException(status_code=422, detail="unknown track")
    session = (session or "Q").strip().upper()
    # ponytail: run_pipeline doesn't return its real lap; this second load hits the pkl cache.
    df, meta = load_real_telemetry(driver, int(year), session, track)
    try:
        pro = _pro_lap_payload(df, meta, driver, year, session, track)
    except Exception:
        traceback.print_exc()
        raise HTTPException(status_code=422, detail="No 3D data for this lap")
    you = _build_you_lap(aligned, pro["points"]["d"], float(report.game_time))

    d = np.asarray(pro["points"]["d"])
    by_id = {int(ci.corner_id): ci for ci in report.corner_insights}
    for c in pro["corners"]:
        ci = by_id.get(int(c["id"])) if c.get("id") is not None else None
        c["time_delta"] = _num(ci.time_delta, 3) if ci is not None else None
        c["your_min_speed_kmh"] = you["speed"][int(np.argmin(np.abs(d - c["apex_m"])))]
    payload.update({"pro": pro, "you": you})
    return payload

/** Your lap as a `points` object: the pro's line (d, x, y, z, steer) with your timing and inputs. */
export function youPoints(pro, you) {
  return { ...pro, t: you.t, speed: you.speed, throttle: you.throttle, brake: you.brake, gear: you.gear };
}

/** Live gap (s) at lap distance d: your time minus the pro's. Positive = you're behind. */
export function gapAt(pro, you, d) {
  return timeAtDistance(you, d) - timeAtDistance(pro, d);
}

/**
 * Stacked traces over lap distance, shaded brake zones, one shared cursor. Click = seek.
 * With `you` (a youPoints object) each row overlays you on the pro and a gap row is added.

export function createTelemetry(el, points, onSeek, you = null, proName = "Pro") {
  const W = 1000, H = 48, n = points.d.length, L = points.d[n - 1];
  const step = Math.max(1, Math.floor(n / 600));

  const zones = [];
  for (let i = 0, start = null; i < n; i++) {
    const on = points.brake[i] >= 0.5;
    if (on && start === null) start = points.d[i];
    if ((!on || i === n - 1) && start !== null) { zones.push([start, points.d[i]]); start = null; }
  }
  const shade = zones.map(([a, b]) =>
    `<rect x="${xOf(a)}" width="${Math.max(2, xOf(b) - xOf(a))}" y="0" height="${H}" fill="var(--accent)" opacity=".15"/>`).join("");

    const lo = r.min ?? Math.min(...all), hi = r.max ?? Math.max(...all), range = hi - lo || 1;
    const yOf = (v) => (H - ((v - lo) / range) * H).toFixed(1);

    return `<div class="l3d-trace"><span class="l3d-trace-label">${r.label}</span>` +
      `<svg viewBox="0 0 ${W} ${H}" preserveAspectRatio="none" aria-hidden="true">${shade}${zero}${lines}` +
